# Фотографии для карточек потоков

Файлы: `cardio.jpg`, `back.jpg`, `office.jpg`, `dance.jpg`, `60plus.jpg`.

Снимок кладётся в плашку целиком, фон **не вырезается**: сверху идёт цветной
оверлей потока. Слой `mix-blend-mode: color` подтягивает собственный фон
снимка к цвету плашки, поэтому подложки разных цветов не спорят между собой,
а правый край растушёван маской — жёсткой границы с заливкой не видно.

Требования к исходнику:
- горизонтальный кадр, человек примерно по центру или левее;
- ровный однотонный фон, всё равно какого цвета;
- голова и плечи в кадре, без обрезки макушки.

Подготовка выполняется скриптом: он уменьшает фигуру внутри кадра, добирает
поля размытой копией снимка и приводит к пропорции карточки. Параметры —
в блоке `FILES` внутри скрипта, доля по X задаёт положение человека.

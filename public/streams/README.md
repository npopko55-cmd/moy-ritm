# Фотографии для карточек потоков

Сюда кладутся изображения людей для левого сайдбара плеера.
Имя файла должно совпадать с id потока из `src/data/streams.ts`:

| Файл          | Поток   | Подпись на карточке              |
|---------------|---------|----------------------------------|
| `cardio.png`  | Кардио  | энергия и жиросжигание           |
| `back.png`    | Спина   | здоровая осанка и сильная спина  |
| `office.png`  | Офис    | разминка для работы              |
| `dance.png`   | Танцы   | движение в удовольствие          |
| `60plus.png`  | 60+     | мягкие тренировки для здоровья   |

Требования:
- PNG с прозрачным фоном (человек вырезан по контуру);
- вертикальный кадр примерно 3:4, высота от 400 px;
- фигура прижата к нижнему краю — карточка обрезает изображение снизу справа;
- левая треть изображения остаётся пустой, там лежит текст.

Пока файла нет, карточка просто рисуется без фотографии — вёрстка не ломается.
